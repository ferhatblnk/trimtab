# trimtab

Automatic effort for Claude Code. trimtab studies a task at high effort, splits it into parts, and runs each part at the lowest effort that gets it right.

Set your session to `/effort medium` while trimtab is on: the main conversation becomes a coordinator at that level, and trimtab raises effort only for the parts that need it.

Documentation, benchmark, and source: https://github.com/ferhatblnk/trimtab
